1. Start your local Bitcoin Core environment in Regtest mode and confirm the node is running successfully.

2. Create two separate wallets representing **User A** and **User B**.

3. Generate at least one receiving address for each wallet and record the addresses.

4. Fund User A’s wallet using Regtest mining or available test coins and verify the wallet balance.

5. Send a specified amount of Bitcoin from User A to User B and capture the transaction ID (TXID).

6. Confirm the transaction by mining blocks (if required), verify the updated balances and transaction details in both wallets, then **submit a document containing all commands used and the corresponding terminal outputs pasted in the exact sequence followed during the exercise**.
